ابزار حامی - آپلود در GitHub

1) محتوای این پوشه (فایل‌ها و پوشه‌ها) را داخل ریپوزیتوری Hami-apk آپلود کن.
   نکته: خود پوشه‌ی hami-tools-ready را آپلود نکن، فقط محتوای داخلش را.
2) پوشه‌ی .github را هم آپلود کن (نقطه‌ای است، اگر مرورگر نیاورد بگو).
3) Commit changes را بزن.
4) تب Actions را باز کن. Build Android APK خودکار اجرا می‌شود (یا Run workflow).
5) بعد از سبز شدن، در همان اجرا بخش Artifacts را باز کن و hami-tools-debug-apk را دانلود کن.
6) فایل .apk را روی گوشی نصب کن.
